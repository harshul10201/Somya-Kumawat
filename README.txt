SOMYA KUMAWAT — FINANCE & ANALYTICS PORTFOLIO

WHAT THE SITE INCLUDES
- Professional introduction and a portrait
- Education and work experience
- Finance, Excel, Tableau and Power BI
- Projects and illustrative financial dashboards
- Certification and achievements
- One-page résumé (open it, then Save as PDF)
- LinkedIn and email

BEFORE PUBLISHING
1. Open site-config.js.
2. Replace YOUR_EMAIL@example.com with the email recruiters should use.
3. Replace the LinkedIn URL with the real profile.
4. Add a portrait as profile.jpg in this folder (a clear, front-facing photo works best). Until that file exists, the site shows a monogram.
5. Review dates, titles and figures in index.html and resume.html.

RÉSUMÉ
Open resume.html and use Save as PDF. That file is the downloadable résumé. It picks up the email and LinkedIn from site-config.js.

PUBLISHING WITH NETLIFY
1. Visit https://app.netlify.com/drop and sign in.
2. Drag this whole folder onto the deploy area.
3. Netlify publishes a *.netlify.app address.
4. In Domain management, add somyakumawat.com and follow the DNS records Netlify shows.
5. Wait for DNS and HTTPS.

The site is static. Dashboard numbers on the project cards are layout examples, not client records.
